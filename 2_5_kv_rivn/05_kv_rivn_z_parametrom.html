Урок 5. Особливості розв'язування квадратних рівнянь з параметрами

Тема 2. Квадратні рівняння та нерівності з параметрами

Квадратне рівняння з параметром має вигляд Ax² + Bx + C = 0, де A, B, C залежать від параметра (або a є параметром).
Алгоритм дослідження:
1. Перевірити випадок, коли старший коефіцієнт дорівнює нулю (рівняння стає лінійним).
2. Якщо A ≠ 0, знайти дискримінант D = B² - 4AC.
3. Розглянути випадки: D < 0 (немає коренів), D = 0 (один корінь), D > 0 (два корені).
4. Записати відповідь залежно від значень параметра.
📌 Задача 1

Для всіх значень параметра a розв'яжіть рівняння
x² + 2x + a = 0.

Показати розв'язання

Розв'язання. Задане рівняння є квадратним для всіх значень параметра \(a\). Знайдемо дискримінант цього квадратного рівняння.

\[ D = 4 - 4a. \]

Далі необхідно розглянути випадки: 1) \(D < 0\); 2) \(D \geqslant 0\).

1) \(D < 0\), тобто \(4 - 4a < 0\); \(4a > 4\); \(a > 1\). Тоді рівняння не має розв'язків.

2) \(D \geqslant 0\), тобто \(4 - 4a \geqslant 0\); \(a \leqslant 1\). Тоді

\[ x_{1,2} = \frac{-2 \pm \sqrt{4 - 4a}}{2}. \]

Зауважимо, що \(\sqrt{4 - 4a} = \sqrt{4(1 - a)} = \sqrt{4} \cdot \sqrt{1 - a} = 2\sqrt{1 - a}\) за умови, що \(a \leqslant 1\). Остаточно отримаємо:

\[ x_{1,2} = \frac{-2 \pm 2\sqrt{1 - a}}{2} = \frac{2(-1 \pm \sqrt{1 - a})}{2} = -1 \pm \sqrt{1 - a}. \]

Відповідь: якщо \(a \leqslant 1\), то \(x_{1,2} = -1 \pm \sqrt{1 - a}\);

якщо \(a > 1\), то рівняння не має розв'язків.

📌 Задача 2

Для всіх значень параметра a розв'яжіть рівняння
ax² + (1 - 2a)x + a - 2 = 0.

Показати розв'язання

1. Випадок \(a = 0\): Рівняння набуває вигляду \(x - 2 = 0\), звідси \(x = 2\).

2. Випадок \(a \neq 0\): Маємо квадратне рівняння. Знайдемо дискримінант:

\[ D = (1 - 2a)^2 - 4 \cdot a \cdot (a - 2) = 1 - 4a + 4a^2 - 4a^2 + 8a = 4a + 1. \]

Розглянемо підвипадки:

а) \(D < 0\), тобто \(4a + 1 < 0 \Rightarrow a < -\frac{1}{4}\). Коренів немає.

б) \(D = 0\), тобто \(a = -\frac{1}{4}\). Один корінь: \(x = -\frac{b}{2a} = -\frac{1 - 2(-\frac{1}{4})}{2(-\frac{1}{4})} = -\frac{1.5}{-0.5} = 3\).

в) \(D > 0\), тобто \(a > -\frac{1}{4}\) (і \(a \neq 0\)). Два корені:

\[ x_{1,2} = \frac{-(1 - 2a) \pm \sqrt{4a + 1}}{2a} = \frac{2a - 1 \pm \sqrt{4a + 1}}{2a}. \]

Відповідь: якщо \(a < -\frac{1}{4}\) — коренів немає; якщо \(a = -\frac{1}{4}\) — \(x = 3\); якщо \(a = 0\) — \(x = 2\); якщо \(a > -\frac{1}{4}, a \neq 0\) — \(x_{1,2} = \frac{2a - 1 \pm \sqrt{4a + 1}}{2a}\).

📌 Задача 3

Для всіх значень параметра a розв'яжіть рівняння
(a² + a - 2)x² + (2a² + a + 3)x + a² - 1 = 0.

Показати розв'язання

1. Перевірка старшого коефіцієнта: \(a^2 + a - 2 = 0 \Rightarrow a_1 = 1, a_2 = -2\).

При \(a = 1\): рівняння набуває вигляду \(0 \cdot x^2 + 6x + 0 = 0 \Rightarrow 6x = 0 \Rightarrow x = 0\).

При \(a = -2\): рівняння набуває вигляду \(0 \cdot x^2 + (8 - 2 + 3)x + 3 = 0 \Rightarrow 9x + 3 = 0 \Rightarrow x = -\frac{1}{3}\).

2. Випадок \(a \neq 1, a \neq -2\): Маємо квадратне рівняння. Знайдемо дискримінант:

\[ D = (2a^2 + a + 3)^2 - 4(a^2 + a - 2)(a^2 - 1). \]

Після розкриття дужок та зведення подібних доданків отримаємо:

\[ D = 17a^2 + 14a + 17. \]

Дискримінант квадратного тричлена відносно \(a\): \(D_a = 14^2 - 4 \cdot 17 \cdot 17 < 0\). Оскільки старший коефіцієнт \(17 > 0\), то \(D > 0\) для будь-якого \(a\).

Отже, корені існують завжди:

\[ x_{1,2} = \frac{-(2a^2 + a + 3) \pm \sqrt{17a^2 + 14a + 17}}{2(a^2 + a - 2)}. \]

Відповідь: якщо \(a = 1\) — \(x = 0\); якщо \(a = -2\) — \(x = -\frac{1}{3}\); якщо \(a \neq 1, a \neq -2\) — \(x_{1,2} = \frac{-(2a^2 + a + 3) \pm \sqrt{17a^2 + 14a + 17}}{2(a^2 + a - 2)}\).

📌 Задача 5

За яких значень параметра a рівняння
(a² - 6a + 5)x² - (a² - 3a + 2)x + a² - a = 0
має більше, ніж два корені?

Показати розв'язання

Квадратне рівняння не може мати більше двох коренів. Рівняння матиме більше двох коренів (тобто безліч), якщо воно перетворюється на тотожність \(0 = 0\).

Це можливо, якщо всі коефіцієнти дорівнюють нулю:

\(\begin{cases} a^2 - 6a + 5 = 0 \\ a^2 - 3a + 2 = 0 \\ a^2 - a = 0 \end{cases}\)

Розв'яжемо кожне: 1) \(a_1 = 1, a_2 = 5\); 2) \(a_1 = 1, a_2 = 2\); 3) \(a_1 = 0, a_2 = 1\).

Спільним коренем для всіх трьох рівнянь є \(a = 1\).

Відповідь: \(a = 1\).

📌 Задача 6

За яких значень параметра a рівняння x² - 2ax + a + 1 = 0 та x² + ax - a - 1 = 0 мають спільний дійсний корінь?

Показати розв'язання

Нехай \(x_0\) — спільний корінь. Тоді:

\(\begin{cases} x_0^2 - 2ax_0 + a + 1 = 0 \\ x_0^2 + ax_0 - a - 1 = 0 \end{cases}\)

Віднімемо від першого рівняння друге:

\(-3ax_0 + 2a + 2 = 0 \Rightarrow 2a + 2 = 3ax_0\).

1) Якщо \(a = 0\), то \(2 = 0\) — неможливо, отже \(a \neq 0\).

2) \(x_0 = \frac{2a + 2}{3a}\). Підставимо в друге рівняння:

\((\frac{2a + 2}{3a})^2 + a(\frac{2a + 2}{3a}) - a - 1 = 0\)

Після спрощення отримаємо: \(4a^2 + 8a + 4 + 6a^2 + 6a - 9a^2 - 9a = 0 \Rightarrow a^2 + 5a + 4 = 0\).

\(a_1 = -1, a_2 = -4\).

Перевіримо, чи є ці корені дійсними для обох рівнянь (дискримінанти \(\geqslant 0\)):

Для \(a=-1\): \(D_1 = 4 - 4(0) = 4 > 0\); \(D_2 = 1 - 4(0) = 1 > 0\).

Для \(a=-4\): \(D_1 = 64 - 4(-3) = 76 > 0\); \(D_2 = 16 - 4(3) = 4 > 0\).

Відповідь: \(a = -1\) або \(a = -4\).

📌 Задача 7

Для яких значень параметра a рівняння
(a + 1)x² + xsqrt{12+a-a^2} + 3 = 0 має:
1) єдиний корінь;
2) два різних дійсних корені?

Показати розв'язання

ОДЗ підкореневого виразу: \(12 + a - a^2 \geqslant 0 \Rightarrow a^2 - a - 12 \leqslant 0 \Rightarrow (a - 4)(a + 3) \leqslant 0 \Rightarrow a \in [-3; 4]\).

1) Єдиний корінь:

а) Рівняння лінійне: \(a + 1 = 0 \Rightarrow a = -1\). При \(a=-1\): \(0 \cdot x^2 + x\sqrt{12 - 1 - 1} + 3 = 0 \Rightarrow x\sqrt{10} + 3 = 0 \Rightarrow x = -\frac{3}{\sqrt{10}}\) — один корінь.

б) Рівняння квадратне, але \(D = 0\). \(D = (\sqrt{12 + a - a^2})^2 - 4(a+1)\cdot 3 = 12 + a - a^2 - 12a - 12 = -a^2 - 11a = -a(a + 11)\).

\(D = 0 \Rightarrow a = 0\) або \(a = -11\). Умова \(a = -11\) не задовольняє ОДЗ. При \(a = 0\): \(x = -\frac{\sqrt{12}}{2} = -\sqrt{3}\) — один корінь.

2) Два різних дійсних корені:

Потрібно, щоб \(a + 1 \neq 0\) (тобто \(a \neq -1\)) та \(D > 0\).

\(-a(a + 11) > 0 \Rightarrow a \in (-11; 0)\). З урахуванням ОДЗ \([-3; 4]\) та \(a \neq -1\), отримуємо \(a \in [-3; -1) \cup (-1; 0)\).

Відповідь: 1) \(a = -1, a = 0\); 2) \(a \in [-3; -1) \cup (-1; 0)\).

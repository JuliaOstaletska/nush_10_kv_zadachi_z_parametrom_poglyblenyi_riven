Урок 6. Застосування теореми Вієта для розв'язування квадратних рівнянь з параметрами

Тема 2. Квадратні рівняння та нерівності з параметрами

Для квадратних рівнянь з параметром другого типу під час розв'язування можна використовувати теорему Вієта. Пригадаємо її:
Якщо \(x_1\) та \(x_2\) – корені зведеного квадратного рівняння \(x^2 + px + q = 0\),
то \(x_1 + x_2 = -p\), \(x_1 \cdot x_2 = q\).
Якщо \(x_1\) та \(x_2\) – корені незведеного квадратного рівняння \(ax^2 + bx + c = 0\),
то \(x_1 + x_2 = -\frac{b}{a}\), \(x_1 \cdot x_2 = \frac{c}{a}\).
Рівності виражають залежність суми і добутку коренів квадратного рівняння від коефіцієнтів і працюють лише у разі наявності коренів квадратного рівняння. Отже, для квадратних рівнянь з параметром обов'язково потрібно перевіряти за допомогою дискримінанта кількість коренів.
📌 Задача 1

За яких значень параметра \(a\) добуток коренів рівняння
x² + (a - 2)x + a² + 2a = 0 дорівнює 3?

Показати розв'язання

За теоремою Вієта для рівняння \(x^2 + px + q = 0\) добуток коренів \(x_1 \cdot x_2 = q\).

У нашому рівнянні \(q = a^2 + 2a\). За умовою \(x_1 \cdot x_2 = 3\).

Отже, маємо рівняння: \(a^2 + 2a = 3 \Rightarrow a^2 + 2a - 3 = 0\).

За теоремою Вієта (або через дискримінант) знаходимо корені: \(a_1 = 1, a_2 = -3\).

Обов'язково перевіримо умову існування дійсних коренів вихідного рівняння (\(D \geqslant 0\)):

\(D = (a - 2)^2 - 4(a^2 + 2a) = a^2 - 4a + 4 - 4a^2 - 8a = -3a^2 - 12a + 4\).

Для \(a = 1\): \(D = -3(1) - 12(1) + 4 = -11 < 0\). Коренів немає! (Значення \(a=1\) не підходить).

Для \(a = -3\): \(D = -3(9) - 12(-3) + 4 = -27 + 36 + 4 = 13 > 0\). Корені існують.

Відповідь: \(a = -3\).

📌 Задача 2

Для якого значення параметра \(a\) сума квадратів коренів рівняння
x² - ax - a - 1 = 0 приймає найменше значення?

Показати розв'язання

Нехай \(x_1, x_2\) — корені. За теоремою Вієта: \(x_1 + x_2 = a\), \(x_1 \cdot x_2 = -a - 1\).

Сума квадратів коренів: \(x_1^2 + x_2^2 = (x_1 + x_2)^2 - 2x_1x_2 = a^2 - 2(-a - 1) = a^2 + 2a + 2\).

Розглянемо функцію \(f(a) = a^2 + 2a + 2\). Це парабола, вітки якої напрямлені вгору. Найменше значення досягається у вершині:

\(a_0 = -\frac{b}{2A} = -\frac{2}{2} = -1\).

Перевіримо, чи існують корені при \(a = -1\): \(D = (-a)^2 - 4(1)(-a - 1) = a^2 + 4a + 4 = (a + 2)^2\).

При \(a = -1\): \(D = (-1 + 2)^2 = 1 > 0\). Корені дійсні.

Відповідь: \(a = -1\).

📌 Задача 3

Для яких значень параметра \(a\) сума квадратів коренів рівняння
(a - 1)x² - 2ax + a + 4 = 0 дорівнює квадрату добутку цих коренів?

Показати розв'язання

Спочатку потрібно, щоб рівняння було квадратним: \(a - 1 \neq 0 \Rightarrow a \neq 1\).

За теоремою Вієта: \(x_1 + x_2 = \frac{2a}{a - 1}\), \(x_1 \cdot x_2 = \frac{a + 4}{a - 1}\).

Умова: \(x_1^2 + x_2^2 = (x_1 x_2)^2\).

Ліва частина: \((x_1 + x_2)^2 - 2x_1x_2 = \left(\frac{2a}{a - 1}\right)^2 - 2\frac{a + 4}{a - 1} = \frac{4a^2 - 2(a + 4)(a - 1)}{(a - 1)^2} = \frac{2a^2 - 6a + 8}{(a - 1)^2}\).

Права частина: \(\left(\frac{a + 4}{a - 1}\right)^2 = \frac{(a + 4)^2}{(a - 1)^2}\).

Прирівнюємо чисельники: \(2a^2 - 6a + 8 = a^2 + 8a + 16 \Rightarrow a^2 - 14a - 8 = 0\).

\(D = 196 - 4(1)(-8) = 196 + 32 = 228\). \(a_{1,2} = \frac{14 \pm \sqrt{228}}{2} = 7 \pm \sqrt{57}\).

Тепер перевіримо умову існування коренів: \(D = (-2a)^2 - 4(a - 1)(a + 4) = 4a^2 - 4(a^2 + 3a - 4) = -12a + 16\).

\(D \geqslant 0 \Rightarrow -12a + 16 \geqslant 0 \Rightarrow a \leqslant \frac{4}{3}\).

Оскільки \(\sqrt{57} \approx 7.5\), то \(a_1 = 7 + 7.5 = 14.5\) (не підходить, бо більше 4/3), а \(a_2 = 7 - 7.5 = -0.5\) (підходить).

Відповідь: \(a = 7 - \sqrt{57}\).

📌 Задача 4

Для яких значень параметра \(a\) рівняння
x² - (|a + 5| - |a - 5|)x + (a - 12)(a + 12) = 0 має два різних від'ємних корені?

Показати розв'язання

Розкриємо модулі. Вираз \(|a+5| - |a-5|\) поводиться по-різному залежно від \(a\). Позначимо \(S = |a+5| - |a-5|\), \(P = a^2 - 144\).

Для того, щоб обидва корені були від'ємними, потрібно:

1) \(D > 0\) (два різних корені);
2) \(x_1 + x_2 < 0\) (сума від'ємна);
3) \(x_1 \cdot x_2 > 0\) (добуток додатний).

За Вієта: \(x_1 + x_2 = S\), \(x_1 \cdot x_2 = P\).

Умова 2: \(S < 0\). Умова 3: \(P > 0 \Rightarrow a^2 - 144 > 0 \Rightarrow a \in (-\infty; -12) \cup (12; +\infty)\).

Умова 1: \(D = S^2 - 4P > 0\). Оскільки корені мають бути дійсними і різними, а \(P>0, S<0\), то \(D\) буде автоматично більше 0, якщо \(S^2 > 4P\).

Розглянемо \(S = |a+5| - |a-5|\). Ця функція набуває значень: 10 (при \(a \geqslant 5\)), \(2a\) (при \(-5 < a < 5\)), \(-10\) (при \(a \leqslant -5\)).

Оскільки нам потрібно \(S < 0\), це можливо лише при \(a < 0\).

З урахуванням \(P > 0\) (\(a < -12\)), маємо \(a < -12\). Тоді \(S = -10\).

Перевіримо \(D > 0\): \((-10)^2 - 4(a^2 - 144) > 0 \Rightarrow 100 - 4a^2 + 576 > 0 \Rightarrow 4a^2 < 676 \Rightarrow a^2 < 169 \Rightarrow -13 < a < 13\).

Перетинаємо умови: \(a < -12\) та \(-13 < a < 13\). Отримуємо \(a \in (-13; -12)\).

Відповідь: \(a \in (-13; -12)\).
